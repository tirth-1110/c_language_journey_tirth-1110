# 🎓 My C Programming Learning Journey

Welcome to my repository tracking my progress through my C programming learning path. This repository acts as my personal learning hub where I store all my practice code, exercises, and mini-projects as a first-semester B.Tech Computer Science student.

---

## 📝 About This Repository
This space is a structured digital notebook for my C source files. As I study the foundations of computer science, I build out individual folders for different topics—starting from basic syntax and data types all the way up to advanced concepts like pointers, memory management, and file handling.

---

## 🚀 How This Repository Helps Me

Building and keeping this repository updated helps me in three major ways:

*   **Hands-on Practice & Backups:** Instead of just reading theory, this repository forces me to write, compile, test, and save my own code. It keeps my practice algorithms safely backed up in the cloud.
*   **Tracking Growth & Consistency:** The contribution graph on my GitHub provides visual motivation to code consistently. Over time, looking back through these files helps me see exactly how much my logic and problem-solving skills have improved.
*   **Building a Future Portfolio:** Sharing my C programs here helps me get comfortable with Git workflows early on. When I am ready to apply for roles or work toward my goal, this repository stands as proof of my strong algorithmic foundation and consistent programming habits.
