## 🚀 How This Repository Helps Me

Building and keeping this repository updated helps me in three major ways:

- **Hands-on Practice & Backups:** Instead of just watching the video, this repository forces me to write, compile, test, and save my own code. It keeps my practice programs safely backed up in the cloud.
- **Tracking Growth & Consistency:** The contribution graph on my GitHub provides visual motivation to code consistently, and the progress tracker above shows exactly how far into the course I am at a glance.
- **Building a Future Portfolio:** Sharing my C programs here helps me get comfortable with Git workflows early on. When I apply for internships, this repository stands as proof of a strong algorithmic foundation and consistent programming habits.
